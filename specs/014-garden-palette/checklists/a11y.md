# Accessibility Checklist: Garden Palette & Options

**Purpose**: Verify a11y for palette selection, Options panel, and six theme combinations  
**Created**: 2026-07-24  
**Feature**: [spec.md](../spec.md)

## Options entry & surface

- [ ] Options IconButton has accessible name (“Options”)
- [ ] `aria-haspopup` / `aria-expanded` reflect Popover state
- [ ] Popover is keyboard-dismissible (Escape) without clearing preferences
- [ ] Focus can move into Popover controls after open
- [ ] `prefers-reduced-motion` does not break open/close

## Palette & Appearance controls

- [ ] Palette group has `aria-label="Palette"` (or equivalent)
- [ ] Appearance group has `aria-label="Appearance"` (or equivalent)
- [ ] Each ToggleButton is operable via keyboard
- [ ] Dev switch has accessible name “Dev”
- [ ] Screen reader announces selected palette / appearance

## Contrast (WCAG AA)

- [ ] Natural × Light — primary text & buttons
- [ ] Natural × Dark — primary text & buttons
- [ ] Vibrant × Light — primary text & buttons
- [ ] Vibrant × Dark — primary text & buttons
- [ ] Dusk × Light — primary text & buttons
- [ ] Dusk × Dark — primary text & buttons

## Header declutter (no lost a11y)

- [ ] Appearance no longer only icon-in-header without replacement
- [ ] Dev still reachable and labelled inside Options
- [ ] Primary header actions (Flow/Focus, Export, Notepad) remain labelled
